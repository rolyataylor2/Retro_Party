This is a collection of cheat code files used with the Nestopia and FCEUX emulators. The goal is to keep this pack up-to-date and be as meticulous as possible. Please report any mistakes or code requests to Reddit user: u/popo31477

To use the codes with Nestopia:
1 - Extract the .xml files to \Nestopia\Cheats
2 - Open a game in Nestopia, go to Options > Cheats > Import.
3 - Browse to the \Cheats directory and find the matching .xml file.

To use the codes with FCEUX:
1 - Extract the .cht files to \FCEUX\Cheats
2 - Open a game in FCEUX, go to Tools > Cheats > Import.
3 - Browse to \Cheats directroy and find the matching .cht file.
4 - All cheats are checked by default, so I would recommend unchecking them before starting your game.
